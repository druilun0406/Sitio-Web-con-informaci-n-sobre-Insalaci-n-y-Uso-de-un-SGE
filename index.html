¿De qué trata este sitio?

Este sitio web es un trabajo académico sobre los Sistemas de Gestión Empresarial (SGE). Está formado por varias páginas donde se explica la teoría y se documenta un caso real: la instalación y uso de Dolibarr, un SGE gratuito y de código abierto.
